MKWii Code Generator

Remap Classic Controller buttons and build Gecko activator codes for Mario Kart Wii, saved as a plain .txt code list.

1. Pick your version and controller

The remapper only hooks the Classic Controller parser. Use the Activators tab for the Wii Wheel, Nunchuk or GameCube controller.

The remapper hook addresses are only known for NTSC-U. Enter the addresses for this version to generate the code.

2. Choose what each button does

Buttons left on “Unchanged” stay mapped one-for-one.
