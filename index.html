MKWii Button Remapper

Choose what each Classic Controller button does in Mario Kart Wii and save the Gecko code as a plain .txt code list.

1. Pick your version and controller

The remapper only hooks the Classic Controller parser, so it can't remap the Wii Wheel, Nunchuk or GameCube controller.

The remapper hook addresses are only known for NTSC-U. Enter the addresses for this version to generate the code.

2. Choose what each button does

Buttons left on “Unchanged” stay mapped one-for-one.
